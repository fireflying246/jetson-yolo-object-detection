两张图片均从 `videos/final_detection_mouse_bottle_20260831.mp4` 直接提取，视频由 Jetson 上的 ROS2 节点使用最终 `models/best.pt` 生成。

| 文件 | 帧/时间 | 结论 |
|---|---|---|
| `success_frame_404.jpg` | 第 404 帧，16.83 s | 黑色鼠标和黄绿色瓶子均正确加框 |
