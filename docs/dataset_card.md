# 最终数据集说明

## 任务与类别

- 任务：YOLO目标检测。
- 类别映射：`0=mouse`、`1=bottle`。旧文件名中的 `cup` 仍表示类别 1。
- 边界框：只包含目标本体，不包含手、线缆或其他背景物体。

## 来源与限制

最终数据集由项目原有基线数据、后续扩充数据和独立测试数据合并得到。原基线数据中的 mouse 与 bottle 各有120张连续拍摄图片，邻近帧相关性较强，因此划分时不能逐张随机分配。原始20张验收测试图片来自独立拍摄会话，并保留在最终 test 集中。

## 最终划分

- 固定种子：`20260825`
- train：1082张图片、1082个标签文件、1163个目标框
- val：131张图片、131个标签文件、158个目标框
- test：37张图片、37个标签文件、37个目标框
- 合计：1250张图片、1250个标签文件、1358个目标框
- 类别目标框：mouse 877个，bottle 481个

压缩包解压后得到 `object_detection/`，其中包含 `images/`、`labels/`、`splits/`、`excluded/` 和 `data.yaml`。压缩包文件清单见 `dataset/dataset_object_detection_final_20260831_manifest.json`，自动检查结果见 `docs/dataset_audit.json`。

最终审计未发现图片缺少标签、标签缺少对应图片、无效类别或坐标，以及跨 train/val/test 的完全相同图片。

## 测试集说明

原始20张验收测试图片为独立拍摄数据，每类10张。最终 test 集扩充为37张，用于计算完整测试指标。后续如继续扩充，应改变背景、照明、距离、拍摄角度和遮挡情况，并避免根据测试结果调参。
